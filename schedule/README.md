# 阿部家カレンダー（schedule/）

> 接骨院のリポジトリに同居していますが、**接骨院とは関係のない阿部家（家庭用）のアプリ**です。
> ホームページ（ルート）・予約システム（`booking/`）・電子カルテ（`emr/`）とは独立して動きます。

家族の予定と献立をいっしょに管理するアプリ（夫婦2人で使う前提、ログインなし）。

## できること（第1段階）

- 月カレンダー（日曜始まり・祝日は赤・今日は黒丸）。左右スワイプで月を移動
- 家族ごとの色分け。複数人の予定は色を並べて表示、仮の予定は薄いストライプ
- 予定ごとに「外出・帰宅時刻」「家で食べない食事（朝・昼・夕）」を登録
- 日付をタップするとポップアップで、その日の予定と献立を表示
  - 朝食・夕食（月曜と木曜はお弁当も）を A/B の2案から選べる
  - 三男向けの味付け・硬さ・大きさの調整を表示
  - 選んだ献立に、子どもごとに「完食／少し／食べず」を記録
- 家にある食材（期限が近い順）と買い物リスト（買ったものは在庫へ移せる）
- 家族と色の設定（名前・色・誕生日・並び順・追加・削除）

## できること（第2段階：献立の提案・費用0円）

- カレンダー上の「🍳 献立」ボタン、または日付のポップアップから、1週間分の A/B 献立を作る
  - アプリに入っているレシピ集（約145品：夕食・朝食・お弁当・汁物・副菜）から、ルールで点数をつけて選ぶ（`src/lib/rulePlanner.ts`）
  - 家にある食材（期限が近いほど優先・期限切れの日には使わない）、最近の献立、「食べた」記録、予定（外食・昼が外の日）をもとに選ぶ
  - お米は1日1食。昼が外の日は必ず朝か夜にお米。麺・パンの夕食は週2回まで（その日は朝をお米に）
  - 三男向けの取り分け方法と、1歳児に注意が必要な食材の警告を表示
- 献立を選ぶと、その案で足りない食材を買い物リストへ自動で追加
- 予定を変えると「この日以降を組み替えますか？」と表示。選んだ献立はそのまま残し、未選択の分だけ作り直す
- 献立と違うものを作った日は「レシピから選ぶ」で記録。レシピ集には家族の定番を追加できる
- 設定画面で「献立に出さない食材・料理」を指定できる

## できること（第3段階：レシートから在庫登録・費用0円）

- iPhone の「ショートカット」で写真の文字を読み取り（端末内の処理で無料）、自動でアプリの登録画面へ
- 設定なしでも、入力欄の「テキストをスキャン」でレシートの文字を入れられる
- 文字から食材を見つけ（`src/lib/receipt.ts`・`src/lib/ingredients.ts`）、期限の目安を付けて登録。買い物リストにあったものは消す

## AI を使う場合（任意・有料）

環境変数 `MEAL_PLANNER=ai` と `ANTHROPIC_API_KEY` を設定すると、献立をレシピ集ではなく Claude が考えます（`src/lib/planner.ts`）。
1週間分で約30円かかります。設定しなければ一切費用はかかりません。

## 技術構成

Next.js 14（App Router）＋ Tailwind CSS ＋ Supabase。Vercel で公開（無料枠）。
データの読み書きはすべてサーバー側（`src/app/api/[table]`）で行い、
Supabase のキーはブラウザに出しません。

## ローカルで動かす

```bash
cd schedule
npm install
npm run dev   # http://localhost:3000
```

Supabase の環境変数が無いときは `.data/db.json` にサンプルデータ付きで保存します（開発用）。
