関節の解剖イラスト（自費カルテ 初診時ページ → 関節の拡大詳細の下地）

このフォルダに画像を置くと、その関節・ビューの下地として自動表示されます。
置かなければ簡易な線画（プレースホルダ）が表示されます。

ファイルの置き方（関節名フォルダ ＋ ビュー名ファイル）:
  public/joints/<関節名>/front.png   … 前面
  public/joints/<関節名>/back.png    … 後面
  public/joints/<関節名>/left.png    … 左側面
  public/joints/<関節名>/right.png   … 右側面

関節名はアプリのボタン名と同じ（日本語でOK）:
  頸部 / 右肩 / 左肩 / 右肘 / 左肘 / 右手首 / 左手首 /
  腰 / 右股関節 / 左股関節 / 右膝 / 左膝 / 右足首 / 左足首

例:
  public/joints/右膝/front.png
  public/joints/右膝/back.png
  public/joints/右膝/left.png
  public/joints/右膝/right.png

推奨: 正方形に近い画像（パッドが正方形のため）。背景は白または透過。
